# Contract examples

The pipeline JSON files cover all six v1 adapters and conform to pipeline.schema.json. They include placeholder profile/model identities and illustrative dimensions. Replace placeholders with profiles verified in the running application. Null package/model revisions must be resolved and recorded by preparation before a live ready bundle is advertised.

create-run.json refers to illustrative immutable resources. sample-events.jsonl is a fictional two-lane BM25 versus hybrid-with-reranking recording showing parallel branches, RRF, rank changes, context selection, streamed answers and final timings.

sample-export-manifest.json demonstrates the export schema. All verification statuses are not_run because this documentation pack is not an implemented or tested application export.

The examples can power an explicitly labeled fixture preview while the application is developed. The live API must never substitute them for actual execution.
